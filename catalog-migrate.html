Catalog Migration

Moves every design image out of catalog.json and onto the NAS.

1 · Read the catalog

Downloads catalog.json from Supabase and counts what is inside. Changes nothing.

2 · Save a backup

Downloads the current catalog.json to this computer. This is the undo button, so it is required before anything is changed.

3 · Migrate

Uploads each image to the NAS and replaces it in the catalog with a short reference.

Safe to stop and safe to re-run. The catalog is saved after every batch, and a half-finished catalog still works — images already moved load from the NAS, the rest load the old way. Nothing is deleted from Supabase.

4 · Verify

Checks that every image the catalog now points at really exists on the NAS.
