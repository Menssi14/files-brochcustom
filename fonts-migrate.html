Font Migration

Copies your font files from Supabase onto the NAS.

1 · See what is there

Lists the fonts in Supabase and the fonts already on the NAS. Changes nothing.

2 · Copy to the NAS

Downloads each font from Supabase and uploads it to the NAS under the same name.

This is a copy, not a move. Nothing is deleted from Supabase, and the tools app keeps reading fonts from Supabase until the code change goes in. Safe to re-run — fonts already on the NAS are skipped.

3 · Verify

Compares every file size on the NAS against Supabase, then renders each font from the NAS copy so you can see it actually works.
